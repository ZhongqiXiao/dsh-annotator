## Process

- 坐标错位的真因：祖先带 transform/filter/will-change/contain 时，fixed 后代的包含块变成该祖先，注入层 host 的 rect 会变成 {y: -scrollY}；lib/overlay.js 新增 hostOrigin() / place()，.box、.lbl、.card 一律减去 host 原点（实测 transform 页 scrollY=200 时 host rect {x:0,y:-200}，box 精确落在 {120,100,200,56}）。
- 遮挡的真因：positionCard 原来固定 `Math.max(8, rect.y - h - 8)`，目标贴顶时卡片压住元素并退到左上角；lib/overlay.js 重写 positionCard：先夹进视口，roomBelow/roomAbove 放不下时按 anchor.y < vh/2 反向选边，intersectsX 决定 below/above 与尖角朝向。
- 抖动的真因：截图统一 `captureBeyondViewport: true` 会改变设备度量/滚动锚点，提交后页面回弹；lib/session.js `_capture` 改为先读 Page.getLayoutMetrics 的 cssLayoutViewport 把 clip 夹进可见区，交集 <4×4 才 beyond=true。
- 自动开窗的真因：lib/client.js select 的 onChange 里直接 `launch(next)`；改为只 `setSavedBrowser` + `rememberBrowser`，按钮按 `switchTarget` 显示「切换到 X」，PANEL_BUILD v26→v27、HOST_REV v26→v27 强刷面板。
- 门径：`npm run verify` exit 0（75 pass / 1 skip），`npm run test:e2e` 11/11；六场景（plain/transform × 小目标/角落/超高）提交后 resize=0、scrollDelta=0。
- 发布链路：main 已推 4e0c611..093559d，tag v0.5.1 单独推送（轻量 tag 不会被 `--follow-tags` 带走）；release.yml 的 publish job 只产 GitHub Release 资产（npm pack + gh release upload），不发布到 npm。
